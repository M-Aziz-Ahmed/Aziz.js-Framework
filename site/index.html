What is Aziz.js?

Aziz.js Framework (published on npm as create-aziz-app) is a Next.js-inspired React framework for building server-rendered applications without a bundler. Pages live in app/, share layouts, and render on the server before the browser hydrates them.

It is designed and maintained by Syed Muhammad Aziz Ahmed. The framework is MIT licensed, open source, and built around native ES modules instead of a proprietary compiler pipeline.

Quick start

npx create-aziz-app my-app
cd my-app
npm install
npm run dev

npm install installs the dev-time JSX compiler. Production builds precompile your modules, so Babel is not needed at runtime.

What you get

File-based routing

Pages, layouts, loading and error files in app/, plus dynamic and catch-all segments.

SSR, SSG and ISR

Server-render by default, prerender at build time, and revalidate on an interval.

API routes and middleware

Node handlers in api/ or app/api/, with a request guard hook in middleware.js.

Security built in

CSRF checks, per-IP rate limiting, CORS control and security headers on every response.

No bundler

The browser imports native ES modules. No webpack, no proprietary runtime, no tree-shaking step.

TypeScript

.ts and .tsx are supported out of the box, with an optional tsc --noEmit check.
