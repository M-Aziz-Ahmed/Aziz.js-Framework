# Syed Muhammad Aziz Ahmed

<img align="right" width="150" src="https://azizahmed.vercel.app/logo.jpg" alt="Syed Muhammad Aziz Ahmed">

**Creator and maintainer of [Aziz.js Framework](https://github.com/M-Aziz-Ahmed/Aziz.js-Framework)** — a Next.js-inspired React framework with file-based routing, SSR, ISR, API routes, and zero runtime dependencies.

I build web applications and developer tools. Aziz.js is my open-source framework for shipping server-rendered React apps without a bundler. See my work at [azizahmed.vercel.app](https://azizahmed.vercel.app/).

## Featured project

### [Aziz.js Framework](https://github.com/M-Aziz-Ahmed/Aziz.js-Framework)

[![npm version](https://img.shields.io/npm/v/create-aziz-app?label=create-aziz-app)](https://www.npmjs.com/package/create-aziz-app)
[![MIT license](https://img.shields.io/npm/l/create-aziz-app)](https://github.com/M-Aziz-Ahmed/Aziz.js-Framework/blob/main/LICENSE)

A lightweight React framework built around native ES modules:

- File-based routing in `app/`, nested layouts, loading and error states
- SSR, SSG, ISR and streaming Suspense
- API routes, middleware, CSRF protection, rate limiting and security headers
- TypeScript support and zero runtime dependencies
- No bundler, no proprietary compiler, no lock-in

```bash
npx create-aziz-app my-app
cd my-app
npm install
npm run dev
```
